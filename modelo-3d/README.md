# MinuteMark · Modelo 3D del punto (Matriz 01)

El primer modelo 3D de un punto MinuteMark: un minimercado de 9,5 m² dentro de una celda de parqueadero (2,43 × 3,90 m), con estantería, equipos de frío, pago y fachada. Se puede girar, acercar y recorrer por vistas, surtido y ficha. Sirve para mostrárselo a cualquier administración.

Es una carpeta independiente: no usa nada de la landing, la oficina ni las propuestas, y ellas no usan nada de aquí. Se puede borrar o mover sin afectar el resto del sitio.
